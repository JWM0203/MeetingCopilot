# 快速开始（普通用户）

面向下载安装包的用户。全程不需要安装 Node.js、Python，也不需要敲任何命令。

English version: [QUICK_START.en.md](QUICK_START.en.md)

---

## 你需要准备什么

| 项目 | 说明 |
|---|---|
| 系统 | Windows 10 / 11（64 位）。macOS 暂无安装包，请见 [INSTALL_MACOS.en.md](INSTALL_MACOS.en.md) |
| 网络 | 能访问你所选服务商的接口即可 |
| API Key | 语音识别与 AI 回答各需要一个（同一服务商可复用）；Key 由你自己创建，费用由服务商收取 |
| 时间 | 第一次配置约 5 分钟，主要花在注册和复制 Key 上 |

MeetingCopilot 采用 **BYOK（自带 Key）**：没有账号系统、没有服务器、不代收任何费用。不清楚 API Key 是什么，先看 [API_KEYS.zh-CN.md](API_KEYS.zh-CN.md)。

---

## 第一步：下载并安装

1. 打开 [Releases 页面](https://github.com/JWM0203/MeetingCopilot/releases/latest)。
2. 下载 `MeetingCopilot-<版本>-win-x64.exe`（安装版）或 `...-win-x64-portable.exe`（免安装版）。两者的区别与安装位置见 [INSTALL_WINDOWS.zh-CN.md](INSTALL_WINDOWS.zh-CN.md)。
3. 当前为未签名的 Beta 版本，Windows SmartScreen 会提示「已保护你的电脑」。确认文件来自上面的官方发布页后，点「更多信息」→「仍要运行」。
4. 建议先核对下载文件的 SHA256：每个 `.exe` 旁边都有同名的 `.exe.sha256` 文件，里面是 CI 构建时算出的哈希值。

---

## 第二步：跟着配置向导走（5 步）

首次启动会自动打开配置向导。它是一个普通的、可以被屏幕共享看到的窗口（方便别人远程帮你），主界面不会同时出现。

### 1️⃣ 欢迎

说明 BYOK 模式、API Key 是什么，以及隐私边界：

- API Key 加密保存在当前电脑；
- 使用云端语音识别时，会议音频会发送给你选择的语音识别服务商；
- 使用云端 AI 回答时，转写文本与你主动导入的资料会发送给你选择的大模型服务商；
- 使用本地语音识别时，音频不出本机。

右上角可以切换 **中文 / English**，这里选的语言就是应用启动后的界面语言。

### 2️⃣ 选择使用方案

| 方案 | 组合 | 需要几个 Key | 适合谁 |
|---|---|---|---|
| **低延迟推荐** | 阿里云百炼实时语音识别 + DeepSeek AI 回答 | 2 个 | 想要最好字幕实时性、中英混说场景 |
| **极简配置** | MiMo 语音识别 + MiMo AI 回答 | 1 个（可勾选共用） | 只想注册一个平台；字幕按整句返回，跟随性弱一些（Beta） |
| **只使用实时转写** | 阿里云百炼实时语音识别 | 1 个 | 暂时不需要 AI 回答 |
| **高级配置与本地模式** | 不改任何设置，直接进入主界面 | 0 个 | 想用本地 FunASR / MOSS / Whisper 或自定义服务商 |

选「高级配置与本地模式」会直接结束向导进入主界面，之后在设置里自行配置。

### 3️⃣ 配置服务

每个服务一张卡片，卡片内自带图文教程：

1. 点「打开官方密钥页面」，在服务商网站创建 Key 并复制；
2. 回到向导，粘贴到输入框（也可以点「从剪贴板粘贴」）；
3. 点「保存并测试连接」。

保存时会自动去掉首尾空格、包裹的引号和 `Bearer ` 前缀。连接测试会发起一次**极小**的真实请求（1 个 token / 约 1.4 秒音频 / 一张 64×64 图片），服务商可能收取极少量费用；测试只在你点击时发生，应用不会在后台偷偷调用。

测试失败时，卡片会给出错误代码和下一步建议，也可以选「暂时保存并稍后重试」。

### 4️⃣ 连接测试

- **测试电脑声音**：先播放任意有声音的内容，再点「开始检测」，看到音量条动起来即可。检测不到声音时，卡片里有排查清单。
- **麦克风（可选）**：启用后会把你自己的发言也单独转写。建议戴耳机，避免扬声器回声。
- **配置检查**：逐项列出 Key 是否已保存、声音是否正常、服务连接测试结果。仍有「未保存」或「暂无声音」时，「下一步」会被挡住。未测试不会挡住流程。

### 5️⃣ 完成

确认方案摘要后点「进入 MeetingCopilot」。向导把整套方案作为**一次**设置写入并关闭，主界面随即出现。

> 配置向导随时可以重开：主界面 **⚙ 设置 → 重新运行配置向导**。重开时主窗口会保持运行，不会退出应用。

## 第三步：开第一场会

1. 让电脑播放有人说话的内容（会议、视频、播客都行）。
2. 点标题栏的 **▶ 开始**，左栏「转录」开始出字。
3. 在对方那句上点 **⚡答**，右栏就会流式生成一段可以直接照着念的回答。
4. 想让 AI 自动接话，打开标题栏的 **持续答**：只有像问题的句子才会触发。
5. 想让回答贴合你的经历，在右栏点 **📄简历** / **📋JD** 导入资料（`.md/.txt/.docx/.pdf`，本地解析，不上传给任何第三方，只有在提问时才作为上下文发给你配置的大模型）。

标题栏还有这些开关：

| 按钮 | 作用 |
|---|---|
| `答:中` / `答:EN` | AI 回答用中文还是英文 |
| `纯文本` / `多模态` | 回答用文本大模型，还是用视觉模型（可截图提问） |
| `🎤麦克风` | 单独转写你自己的声音 |
| `隐身开/关` | 窗口对录屏 / 共享 / 截图不可见（Windows 有效，macOS 尽力而为） |
| `—` | 隐藏窗口；用快捷键或系统托盘图标再呼出 |

---

## 窗口不见了？

主窗口默认不在任务栏显示，隐藏后有两条路回来：

- 按呼出快捷键（默认 `Control+B`，设置里可改）；
- 点系统托盘（右下角）里的 MeetingCopilot 图标，或右键菜单里的「显示窗口」。

托盘菜单还提供「开始 / 停止转写」「新建会话」「设置」「服务状态」「帮助与教程」「检查更新」「退出」。第一次隐藏窗口时会有一次气泡提示，之后不再重复。

---

## 遇到问题

1. 先看应用内的 **帮助与教程**（托盘菜单或 设置 → 帮助与教程），内容离线可读。
2. 再看 [TROUBLESHOOTING.zh-CN.md](TROUBLESHOOTING.zh-CN.md)，里面有完整的错误代码表。
3. 仍未解决：设置 → 高级设置 → 诊断信息，复制报告（不含 Key、简历和转写内容）后到 [GitHub Issues](https://github.com/JWM0203/MeetingCopilot/issues) 反馈。
